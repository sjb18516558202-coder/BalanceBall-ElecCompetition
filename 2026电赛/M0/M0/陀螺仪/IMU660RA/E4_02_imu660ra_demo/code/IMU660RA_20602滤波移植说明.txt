IMU660RA 按 ICM20602 陀螺仪滤波算法移植说明

本版本是在 E4_imu(6).zip 的 IMU660RA 示例工程基础上修改。

一、主要新增文件
1. user/inc/imu660ra_filter.h
2. user/src/imu660ra_filter.c

二、主程序修改
1. user/src/main.c 已改为 IMU660RA + IPS200 显示版本。
2. 上电后先 imu660ra_init()，再 imu660ra_filter_init()。
3. 静止校准约 4 秒：imu660ra_filter_calibrate(800)。
4. 使用 PIT_TIM_G0 每 5ms 调用 imu660ra_filter_update(IMU660RA_FILTER_DT)，避免屏幕刷新/串口打印拖慢 Yaw 积分。
5. IPS200 显示 Roll、Pitch、Yaw、Gx/Gy/Gz、转角误差和状态。

三、算法内容
移植自你提供的 ICM20602 滤波工程，包含：
1. 三点中值滤波，压制尖峰。
2. 上电静止零偏校准。
3. 自适应低通滤波，震动时自动降低截止频率。
4. 静止检测与在线零偏学习，降低 Z 轴 Yaw 漂移。
5. Mahony / Madgwick / Mahony+Kalman 三种融合框架，默认 Mahony+Kalman。
6. 平装小车专用 Z 轴积分 Yaw，保留转90度闭环接口。

四、IMU660RA 底层参数修改
1. zf_device_imu660ra.h：加速度默认量程由 ±8G 改为 ±4G，提高分辨率。
2. zf_device_imu660ra.h：陀螺仪默认量程由 ±2000DPS 改为 ±500DPS，提高转角积分分辨率。
3. zf_device_imu660ra.c：加速度采样由 50Hz 改为 200Hz，匹配 5ms 滤波周期。

五、常用读取值
1. imu660ra_filter_data.yaw_deg：平装小车转角，转90度主要看这个。
2. imu660ra_filter_data.yaw_rate_dps：实际参与 Yaw 积分的 Z 轴角速度。
3. imu660ra_filter_data.gz_dps：滤波补偿后的 Z 轴角速度，可做转向速度反馈。
4. imu660ra_filter_data.roll_deg / pitch_deg：车身姿态角。

六、调参位置
1. 如果实际转90度，屏幕只显示88度：
   在 main 初始化后调用 imu660ra_filter_set_yaw_scale(90.0f / 88.0f);
   或在 imu660ra_filter.c 中修改 static float yaw_scale。
2. 如果静止时 Yaw 还飘：
   调整 imu660ra_filter_set_yaw_opt(deadband_dps, bias_alpha, hold_enable)。
   常用 deadband_dps = 0.4~1.0，bias_alpha = 0.0002~0.002，hold_enable = 1。

七、注意事项
1. 校准时小车必须完全静止，否则零偏会被算错。
2. IMU660RA 官方驱动当前没有开放温度原始值，本移植版保留温漂接口，但 temperature_c 暂固定为 25℃。
3. 六轴 IMU 没有磁力计，Yaw 是相对角度，不能做到长期绝对不漂。


八、2026-06-19 回零误差优化说明
针对“转90度再转回来还有约1.7度残差”的问题，本版进一步修改了 Yaw 积分策略：
1. Yaw 积分不再直接使用显示用的 gyro_lpf_dps.z，而是新增 yaw_gyro_integral_dps 专用通道，截止频率约95Hz，减少低通相位滞后。
2. 转向判断增加滞回：超过0.85°/s进入转向，小于阈值后不会立刻切回大死区，而是继续保持约220ms小死区。
3. 转向结束后约500ms内冻结Z轴零偏学习，避免把慢速回零尾段误学成零偏。
4. 默认普通Yaw死区由0.65°/s降到0.42°/s，转向死区由0.06°/s降到0.035°/s，减少慢速转动被吞掉。
5. 静止判定略收紧，减少刚停下时误锁Yaw。

如果你测试后还剩0.5~1度残差：
- 优先把 imu660ra_filter_set_yaw_opt(0.30f, 0.00065f, 1) 放到校准完成后测试；
- 如果静止时开始慢慢飘，再把 deadband 调回 0.42f 或 0.55f；
- 如果每次都固定偏大或偏小，再用 imu660ra_filter_set_yaw_scale() 做比例校准。
