Yaw 转 90°只显示 50°的原因与修正
====================================

一、现象判断
真实旋转 90°，Yaw 显示约 50°，这不是普通零漂，而是比例偏小。
优先排查两个原因：
1. 滤波更新周期 dt 不真实：代码写 5ms，但屏幕刷新、printf、小车控制逻辑会拖慢主循环。
   算法仍按 5ms 积分，实际周期若接近 9ms，就会出现 90°只显示约 50°。
2. 陀螺仪量程太小：原默认 ±250dps。手动快速转 90°或小车快速原地转向时，很容易超过 250°/s，传感器输出饱和，积分角度偏小。

二、本版已经修改
1. main.c：滤波更新改为 PIT 定时器 5ms 固定调用，屏幕和串口不再影响 Yaw 积分。
2. zf_device_icm20602.h：陀螺仪默认量程由 ±250dps 改为 ±1000dps，降低快速旋转饱和风险。
3. zf_device_icm20602.c：陀螺仪硬件 DLPF 改为约 41Hz，提高转向响应。
4. icm20602_filter.c：软件陀螺仪低通截止频率提高，避免转向角度响应过慢。
5. 增加 icm20602_filter_set_yaw_scale(scale) 接口，用于最后的比例标定。

三、测试方法
1. 上电后保持小车静止，等待校准完成。
2. 调用 icm20602_filter_reset_yaw()，或者按复位后从 0 开始测试。
3. 水平慢慢旋转 90°，不要特别快。
4. 观察 Yaw 显示。

四、如果新版仍然偏小
如果真实 90°，显示 80°，可以设置：
    icm20602_filter_set_yaw_scale(90.0f / 80.0f);

如果真实 90°，显示 50°，可以临时设置：
    icm20602_filter_set_yaw_scale(90.0f / 50.0f);   // 也就是 1.8

建议先用新版直接测试，不要一开始就加 1.8，因为本版已经修正了 dt 和量程问题。

五、小车实际使用建议
1. 小车转向控制优先使用 gz_dps 做角速度闭环。
2. 短时间转 90°、180°可以使用 yaw_deg。
3. 每次执行固定角度转向前，调用 icm20602_filter_reset_yaw() 清零相对角度。
4. ICM20602 没有磁力计，Yaw 长时间绝对方向一定会漂，长距离导航需要融合编码器/磁力计/视觉/外部定位。
