ICM20602 数据显示到 IPS200 说明

1. 本工程已在 E4_05_icm20602_demo/user/src/main.c 中加入 IPS200 显示。

2. 初始化顺序：
   clock_init(SYSTEM_CLOCK_80M);
   debug_init();
   ips200_init(IPS200_TYPE_SPI);
   ips200_set_dir(IPS200_CROSSWISE);
   icm20602_init();

3. 屏幕显示内容：
   ACC X/Y/Z  ：ICM20602 加速度计三轴原始值
   GYRO X/Y/Z ：ICM20602 陀螺仪三轴原始值

4. 默认 IPS200 接线在 libraries/zf_device/zf_device_ips200.h：
   SCL  -> A12
   SDA  -> A9
   RST  -> A7
   DC   -> A15
   CS   -> A8
   BLK  -> A13

5. 默认 ICM20602 接线在 libraries/zf_device/zf_device_icm20602.h：
   SCLK -> B23
   MOSI -> B22
   MISO -> B21
   CS   -> B19

6. ICM20602 使用 SPI_1，IPS200 使用 SPI_0，默认不冲突。
   如果你改了引脚，注意不要让两个设备共用不同 SPI 宏导致冲突。

7. 当前屏幕默认显示的是 raw 原始值。
   如果要显示 g 和 °/s，可以在 main.c 中使用：
   icm20602_acc_transition(icm20602_acc_x)
   icm20602_gyro_transition(icm20602_gyro_x)
