ICM20602 小车产品级滤波升级说明
============================================================

一、本版本解决的问题
------------------------------------------------------------
1. 原始陀螺仪数据抖动大：加入中值滤波、自适应低通和可选二阶陷波器。
2. 小车电机/底盘震动影响角度：根据加速度模长、jerk、角速度幅值判断震动状态，震动时降低加速度融合权重。
3. 陀螺仪零漂/温漂：上电静止零偏校准 + 静止在线零偏学习 + 温漂系数接口。
4. 角度融合不稳定：内置 Mahony、Madgwick、Mahony+一维 Kalman 三套方案，默认启用 Mahony+Kalman。
5. 静止时角速度残留导致 Yaw 慢慢漂：加入 ZARU（零角速度更新）思路，静止时把残余角速度缓慢压向 0。

二、新增/修改文件
------------------------------------------------------------
1. user/inc/icm20602_filter.h
2. user/src/icm20602_filter.c
3. user/src/main.c
4. libraries/zf_device/zf_device_icm20602.c
   已设置 200Hz 采样，开启 ICM20602 硬件 DLPF。

三、默认算法链路
------------------------------------------------------------
ICM20602 原始数据
    ↓
三点中值滤波：去除 SPI 偶发毛刺、冲击尖峰
    ↓
陀螺仪上电零偏补偿 + 温漂补偿接口 + 在线零偏学习
    ↓
可选二阶陷波器：默认关闭，适合已测得固定电机震动频率时打开
    ↓
自适应一阶低通：震动越大，截止频率越低
    ↓
震动/运动状态检测：STOP / MOVE / VIB
    ↓
姿态融合：默认 Mahony + 一维 Kalman
    ↓
输出 Roll / Pitch / Yaw / 滤波后角速度 / 温度 / 加速度模长

四、算法选择方法
------------------------------------------------------------
在 user/inc/icm20602_filter.h 中修改：

#define ICM20602_FUSION_ALGORITHM       ICM20602_FUSION_MAHONY_KALMAN

可选值：
1. ICM20602_FUSION_MAHONY
   经典 Mahony 非线性互补滤波，运算量低，适合普通实时姿态输出。

2. ICM20602_FUSION_MADGWICK
   Madgwick 梯度下降 AHRS，参数少，嵌入式常见。若想和开源 AHRS 算法对比，可切换到该模式。

3. ICM20602_FUSION_MAHONY_KALMAN
   默认推荐。Mahony 维护四元数和 Yaw，一维 Kalman 对 Roll / Pitch 做二次融合。
   小车场景中 Roll / Pitch 会受加减速和震动影响，该方案更稳。

五、使用注意
------------------------------------------------------------
1. 上电校准时，小车必须静止约 4 秒。
   如果手拿着晃，陀螺仪零偏会校准错，后面角度会漂。

2. ICM20602 是六轴 IMU，没有磁力计，所以 Yaw 不能长期绝对稳定。
   Roll/Pitch 有重力方向修正，会稳定得多；Yaw 只能作为短时间相对角度。
   如果要长时间稳定航向，建议融合编码器、磁力计、视觉或外部定位。

3. 默认不开启二阶陷波器。
   只有当你用串口记录数据、FFT 分析后发现有固定频率震动，例如 60Hz、70Hz，才建议打开：
   #define ICM20602_NOTCH_ENABLE  1U
   #define ICM20602_NOTCH_FREQ_HZ  实测频率

4. 温漂系数不是固定值。
   同一型号不同芯片、不同安装方式都有差异。若要做更严格产品校准，需要让小车静止，在低温/常温/高温分别记录 gx/gy/gz，然后拟合 °/s/℃ 系数，再调用：
   icm20602_filter_set_gyro_temp_coeff(gx_k, gy_k, gz_k);

六、现场调参建议
------------------------------------------------------------
1. 如果小车静止时角度还抖：
   适当降低 ICM20602_VIB_ACC_CUTOFF_HZ、ICM20602_VIB_GYRO_CUTOFF_HZ，或者增大 Kalman 的 r_measure。

2. 如果小车运动时角度响应太慢：
   适当提高 ICM20602_NORMAL_ACC_CUTOFF_HZ、ICM20602_NORMAL_GYRO_CUTOFF_HZ，或者减小 Kalman 的 r_measure。

3. 如果车一加速 Roll/Pitch 明显被带偏：
   适当减小 acc_weight 计算中的阈值，或者让震动状态下 acc_weight 乘得更小。

4. 如果 Yaw 漂移仍明显：
   这是六轴 IMU 的物理限制。可以提高静止判断准确性，静止时调用 icm20602_filter_reset_yaw()，或者加入编码器/磁力计/视觉约束。

七、参考算法来源
------------------------------------------------------------
1. Mahony 等：Nonlinear Complementary Filters on the Special Orthogonal Group，常用于 IMU 姿态互补滤波。
2. Madgwick：An efficient orientation filter for inertial and inertial/magnetic sensor arrays，常用于低算力嵌入式 AHRS。
3. Kalman：本版本用一维角度 Kalman，不是完整 EKF。对小车 Roll/Pitch 足够实用，计算量比完整 EKF 小很多。
4. Allan variance：用于分析陀螺仪随机游走、零偏稳定性。产品级标定时建议长期静止采样后分析。
