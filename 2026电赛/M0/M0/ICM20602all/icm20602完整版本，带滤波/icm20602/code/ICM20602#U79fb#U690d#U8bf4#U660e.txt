ICM20602 移植说明

1. 新增驱动文件
   libraries/zf_device/zf_device_icm20602.c
   libraries/zf_device/zf_device_icm20602.h

2. 默认接线
   SCLK/SPC -> B23，即 ICM20602_SPC_PIN = SPI1_SCK_B23
   MOSI/SDI -> B22，即 ICM20602_SDI_PIN = SPI1_MOSI_B22
   MISO/SDO -> B21，即 ICM20602_SDO_PIN = SPI1_MISO_B21
   CS/NCS   -> B19，即 ICM20602_CS_PIN  = B19
   VCC      -> 3.3V
   GND      -> GND

3. 如果接线不同
   修改 libraries/zf_device/zf_device_icm20602.h 文件中的 ICM20602_SPI、ICM20602_SPC_PIN、ICM20602_SDI_PIN、ICM20602_SDO_PIN、ICM20602_CS_PIN。

4. 默认量程
   加速度：±4g
   陀螺仪：±250dps
   可在 zf_device_icm20602.h 中修改 ICM20602_ACC_SAMPLE_DEFAULT 和 ICM20602_GYRO_SAMPLE_DEFAULT。

5. 常用函数
   icm20602_init();          // 初始化，返回 0 表示成功，返回 1 表示失败
   icm20602_get_acc();       // 读取加速度
   icm20602_get_gyro();      // 读取陀螺仪
   icm20602_get_acc_gyro();  // 一次读取加速度、温度、陀螺仪

6. 常用变量
   icm20602_acc_x,  icm20602_acc_y,  icm20602_acc_z
   icm20602_gyro_x, icm20602_gyro_y, icm20602_gyro_z
   icm20602_temp_raw

7. 物理量换算
   加速度单位 g：   icm20602_acc_transition(icm20602_acc_x)
   陀螺仪单位 °/s： icm20602_gyro_transition(icm20602_gyro_x)
