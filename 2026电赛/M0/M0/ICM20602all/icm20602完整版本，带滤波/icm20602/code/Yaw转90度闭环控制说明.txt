Yaw转90度闭环控制说明
====================

一、为什么小车“有时候不是90度”
------------------------------
1. 如果用开环延时转弯，小车受电池电压、地面摩擦、轮胎打滑影响，每次转角都会不一样。
2. 如果代码写成“Yaw到90度立刻停电机”，车体还有惯性，停电机后会继续转一点，容易过冲。
3. 上一版为了压Yaw漂移，静止锁定和Yaw死区偏强，快到90度减速的低角速度尾段可能被吃掉。
4. 如果陀螺仪量程太小，小车转得太快时会饱和，实际90度可能只积分出80度、70度甚至更小。

二、本版改动
------------
1. 转向过程中自动进入“转向模式”：Yaw死区从普通模式的大死区降为 0.06 dps。
2. 转向过程中禁止Z轴在线零偏学习，避免把真实转向角速度误当成漂移扣掉。
3. 加入目标转角闭环接口：不是等到90度突然停，而是根据剩余角度和角速度提前减速。
4. 默认陀螺仪量程改为 ±1000dps，降低小车快速原地转向时饱和丢角度的概率。

三、推荐调用方式
----------------
滤波更新仍然由PIT定时器固定200Hz完成，主循环只调用目标转角控制接口即可。

示例：让小车向一个方向转90度

    // 转向开始前调用一次
    icm20602_filter_yaw_turn_start(90.0f);

    while(!icm20602_filter_yaw_turn_is_done())
    {
        float turn = icm20602_filter_yaw_turn_update();   // 输出范围 -1.0 ~ 1.0

        // 下面的 motor_set 只是示例，需要替换成你自己的电机控制函数。
        // turn > 0 和 turn < 0 分别对应两个旋转方向，方向不对就把左右电机符号对调。
        motor_left_set_speed( -turn * TURN_PWM_MAX );
        motor_right_set_speed( turn * TURN_PWM_MAX );
    }

    motor_left_set_speed(0);
    motor_right_set_speed(0);

四、几个重要调参
----------------
如果转到目标附近还过冲，说明转得太猛或刹车太晚，可以这样调：

    icm20602_filter_yaw_turn_set_param(0.025f, 0.016f, 0.55f, 0.15f, 1.5f, 6.0f);

含义：
- kp = 0.025：转向力度稍小
- kd = 0.016：提前刹车更强
- max_output = 0.55：最大转向输出变小
- min_output = 0.15：最小输出变小，接近目标不容易冲过头
- finish_error = 1.5度：误差小于1.5度认为角度接近
- finish_rate = 6dps：角速度也要小于6dps才算真正停稳

如果转不到90度就停，可能是电机最小输出不够，或者finish条件太宽，可以这样调：

    icm20602_filter_yaw_turn_set_param(0.035f, 0.010f, 0.70f, 0.22f, 1.0f, 5.0f);

五、如果Yaw显示本身就不准
------------------------
先手动慢慢旋转90度，看屏幕Yaw是不是接近90。
如果每次都固定偏小，例如真实90，显示86，可加比例校准：

    icm20602_filter_set_yaw_scale(90.0f / 86.0f);

如果有时候准、有时候不准，不要先改scale，优先检查：
1. 小车是否打滑；
2. 转速是否太快；
3. 电池电压是否变化大；
4. 是否用开环延时控制；
5. 是否在调用目标转角闭环接口。

六、屏幕显示说明
----------------
Yaw：当前累计相对角度。
Err：目标转角剩余误差，调用 yaw_turn_start 后才有意义。
Out：闭环控制输出，范围 -1~1，给左右轮差速用。
Gz：滤波后的Z轴角速度。

注意：ICM20602没有磁力计，Yaw没有绝对方向参考。短时间转90度可以做得比较准，长期航向保持建议融合编码器。
