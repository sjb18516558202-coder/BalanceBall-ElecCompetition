ICM20602 小车产品级滤波说明
===========================

一、这版程序解决的问题
1. 不再直接显示 ICM20602 原始值，而是输出滤波后的角速度和姿态角。
2. 上电静止校准陀螺仪零偏，减少静止时角速度不为 0 的问题。
3. 加入温度基准和静止在线零偏学习，减小温漂导致的慢慢偏移。
4. 加入中值去尖峰 + 自适应低通，降低电机、车体、地面震动对数据的影响。
5. 加入 Mahony 六轴姿态融合，输出 Roll、Pitch、Yaw，更适合小车使用。

二、使用方法
1. 上电后屏幕会提示 Calibrating gyro...
2. 此时小车必须保持静止，建议放在水平桌面上，等待约 4 秒。
3. 校准完成后屏幕显示：
   Roll  ：横滚角，单位 °
   Pitch ：俯仰角，单位 °
   Yaw   ：航向角，单位 °
   Gx/Gy/Gz：滤波后的角速度，单位 °/s
   AccN  ：加速度模长，正常静止时应接近 1.000g
   Temp  ：芯片温度，单位 ℃
   State ：STOP/MOVE/VIB，分别表示静止、运动、震动明显

三、重要说明
1. ICM20602 只有加速度计和陀螺仪，没有磁力计，所以 Yaw 不能做到长期绝对不漂移。
   Roll 和 Pitch 有重力方向修正，长期稳定性会明显好于 Yaw。
2. 小车电机震动较大时，程序会降低加速度修正权重，避免把震动/加减速误认为姿态变化。
3. 小车静止时，程序会慢慢学习陀螺仪残余零偏，用来抑制温漂。
4. 如果需要更极致的温漂补偿，需要在不同温度下实测陀螺仪零偏，然后填写 icm20602_filter.c 中的 gyro_temp_k_dps_per_c。

五、调参建议
1. 震动特别大：
   - 降低 ICM20602_VIB_ACC_CUTOFF_HZ，例如 8 改成 5。
   - 降低 ICM20602_VIB_GYRO_CUTOFF_HZ，例如 18 改成 12。
2. 角度响应太慢：
   - 提高 ICM20602_NORMAL_ACC_CUTOFF_HZ，例如 20 改成 30。
   - 提高 ICM20602_NORMAL_GYRO_CUTOFF_HZ，例如 35 改成 45。
3. 静止角度慢慢偏：
   - 确认上电校准时小车真的没有动。
   - 检查 ICM20602 是否固定牢靠，不能悬空、晃动或只靠杜邦线吊着。
4. Yaw 长时间漂移：
   - 这是六轴 IMU 的正常限制。要绝对航向，需要加磁力计、视觉、编码器里程计或外部定位。
