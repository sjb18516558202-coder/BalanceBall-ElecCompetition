# 42688car

这是基于原 MSPM0G3507 CCS 工程整理出来的智能小车模板代码。

当前这版代码的特点：

- 按键只置标志位，不直接处理动作
- PID 已经简化，尽量接近原模板工程写法
- 串口模块只保留底层接口，不在 `main.c` 里做命令解析
- 不接陀螺仪时，也可以先测试电机、编码器、速度环

主要文件：

- `empty.syscfg`
  SysConfig 硬件外设和引脚配置。

- `main.c`
  初始化、主循环、10ms 控制定时器中断入口。

- `control.c / control.h`
  小车控制主逻辑。

- `pid.c / pid.h`
  简化后的 PID 模块。

- `key.c / key.h`
  三个按键消抖和标志位。

- `CODE_EXPLANATION.md`
  当前这版代码对应的参考文档，包含：
  - 所有主要接口
  - 重要函数
  - 关键参数
  - 引脚说明
  - 正确的调试顺序

建议先看 `CODE_EXPLANATION.md`，再看代码。它已经把“先测什么、后测什么”写清楚了。
