常用调用方式：

Motor_Set_Speeds(0, 20, 0, 0);              // 只让第 2 个电机速度为 20
Motor_Set_One_Speed_By_Number(2, 20);       // 同上，推荐写法
Motor_Set_One_Speed(1, 20);                 // 同上，编号从 0 开始
Motor_Stop_All();                           // 停止全部电机

注意：
- Motor_Set_One_Speed_By_Number() 的电机编号是 1~4。
- Motor_Set_One_Speed() 的电机编号是 0~3。
- 正负号表示方向，如果方向不对，可以先把速度取反测试。
